# DIY Smart Home Robotics API

Backend API for the DIY Smart Home Robotics community.

## Endpoints

- `/gradio` - Gradio UI interface
- `/api/health` - Health check
- `/api/tutorials` - List/get tutorials
- `/api/videos` - List/get videos
- `/api/forum` - Forum threads and replies
- `/api/contact` - Contact form
- `/api/newsletter` - Newsletter subscription
- `/api/visits` - Visit tracking
